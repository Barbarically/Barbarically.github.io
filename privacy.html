Keyline Privacy Policy

Last updated: November 23, 2026

Keyline is a local Chrome extension for keyword research. This policy explains how it handles Google user data.

Data Keyline accesses

When the user connects Google Ads, Keyline uses the Google Ads OAuth scope to request Keyword Planner metrics for keywords the user chooses to research. The extension may access the connected Google Ads customer and manager account identifiers needed to make those requests.

How data is used

Google user data is used only to authenticate the user and retrieve Google Ads Keyword Planner metrics for display inside Keyline. Keyline does not use Google user data for advertising, profiling, or model training.

Storage and sharing

OAuth credentials, account identifiers, settings, and cached keyword results are stored locally in Chrome extension storage on the user’s device. Keyline does not operate a remote application server and does not sell or share Google user data. Requests are transmitted directly to Google’s OAuth and Google Ads API endpoints.

Retention and deletion

Local settings and cached results remain until the user clears extension data or removes the extension. The user can revoke Keyline’s Google access from their Google Account security settings.

Security

Keyline limits access to the permissions required for its keyword-research features. Users should protect access to their Chrome profile and device.

Contact

Questions about this policy may be submitted through the Keyline site repository.
